# Project_userSearchFilter_JS
A responsive user filtering interface built with HTML, CSS, and JavaScript. It enables real-time search to filter user profiles by name. Designed with a clean, modern UI, it demonstrates interactive front-end components useful for E-commerce platforms, Business dashboards, and Projects displays.
